# Native Host MVP 调试器

这是一个简化的 Native Host 实现，用于理解和调试 Chrome 扩展与本地 MCP 服务器的通信机制。

## 🚀 快速开始

1. 打开 `index.html` 文件
2. 使用 Live Server 或直接在浏览器中打开
3. 点击 "连接原生主机" 按钮开始测试

## 📁 文件结构

```
mvp/native-host/
├── index.html              # 调试界面
├── simple-native-host.ts   # 简化的实现
└── README.md              # 本文档
```

## 🎯 功能特性

- **连接管理**: 模拟与本地 MCP 服务器的连接
- **状态监控**: 实时显示服务器状态
- **消息日志**: 完整的消息交互记录
- **工具调用测试**: 测试各种 MCP 工具调用
- **响应模拟**: 模拟服务器的各种响应

## 🔧 使用方法

### 基础调试
1. 打开调试器页面
2. 设置端口号（默认 3000）
3. 点击连接按钮
4. 查看日志和状态变化

### 消息类型测试
- 连接/断开连接
- 获取服务器状态
- 模拟工具调用
- 错误处理

## 🎛️ 控制台命令

在浏览器控制台中，你可以使用以下命令：

```javascript
// 手动连接
window.connect()

// 断开连接
window.disconnect()

// 获取状态
window.getStatus()

// 测试工具调用
window.testToolCall('list_files')
```

## 🧪 扩展开发

## 🔍 学习要点

通过这个 MVP 可以理解：
- Chrome 原生消息通信机制
- 扩展与本地应用的交互流程
- 状态管理和消息路由
- 异步通信模式
